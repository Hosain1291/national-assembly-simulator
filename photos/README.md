# 인물 사진 모음 (제헌국회 ~ 22대)

시뮬레이터에 나오는 국무위원·주요 인물 사진을 국회별 폴더에 모읍니다.

```
photos/
  01/ … 22/        국회별 폴더 (01 = 제헌국회)
    README.md      그 국회의 인물·역할·분야·파일 이름·원본 링크 목록
    이름.webp      사진 파일 (이름.확장자)
  links.json       전체 목록 (기계가 읽는 용도)
  download.py      links.json 의 원본 링크에서 사진을 한꺼번에 내려받는 스크립트
```

## 규칙
- 파일 이름은 시뮬레이터에 적힌 이름 그대로 씁니다. 예: `photos/15/이수성.webp`
- 동명이인은 같은 국회 안에서만 쓰이므로 국회 폴더로 구분됩니다.
- 사진이 폴더에 들어오면 시뮬레이터는 외부 링크 대신 이 폴더의 파일을 씁니다.

## 원본 링크에서 한꺼번에 받기
```
python3 photos/download.py
```
나무위키 등 원본 사이트가 막히지 않은 컴퓨터에서 실행하면, 아직 없는 사진을 각 폴더에 저장합니다.
